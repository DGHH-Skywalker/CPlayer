# NoiseLimiter

只提供动态压制，默认强度 50、输出上限 −12 dBFS。强度范围 0–100，上限范围 −30 至 −3 dBFS。没有模式选择框和基础强度控件，界面只保留滑块、数值、状态和错误。最高强度优先降低冲击感，会显著牺牲低频和整体音色。

## 处理路径

原生音乐在交叉混音、均衡、归一化与最终音量之后，进入按完整音频帧处理的 Rust DSP；CPAL 与 Windows WASAPI 共用该出口。参数使用单个原子快照，实时回调不分配内存、获取锁或调用脚本。预分配干声与三频段的 5 ms 预读延迟，检测端先于实际输出取得衰减，所有声道联动，最终限制输出峰值。

B 站普通浏览和哔哩Song 使用同一份 Rust 算法编译出的本地 WASM，经 AudioWorklet 处理。主世界在站点首次脚本前拦截媒体播放；初始化期间先连接保守限幅图，随后切换 WASM。网页不能通过诊断回报修改应用参数。参数修改不重载网页，也不主动恢复暂停的视频。媒体全部暂停后挂起 AudioContext，显式播放后恢复，避免后台持续处理静音。受跨域限制而无法安全接入音频图的媒体暂停并显示错误。

采用 300 Hz / 2500 Hz Linkwitz–Riley 四阶分频与低频支路相位补偿，减少鼓点从中频残差泄漏。检测器即时捕获峰值，增益以 0.15 ms 起音、120–240 ms 释放，压制作用于延迟后的频段，覆盖第一下鼓点。另以峰值相对慢速能量的突增检测压住短促瞬态，不依赖整首歌曲平均响度。

强度上半程采用更激进曲线：100 时低频阈值 −38 dB、比率 24:1、附加衰减 24 dB，高频阈值 −40 dB、比率 18:1、附加衰减 10 dB；中频采用较温和比率以保留部分人声主体。没有补偿增益。最终上限取用户上限与 `−36 × (强度 / 100)³ dBFS` 中更低者，100 时整条输出不超过 −36 dBFS，不能靠把输出上限调高绕过最大压制。

插件异常时保留最后动态参数与输出上限。浏览器初始化和处理器故障采用同样的强度安全上限；资源校验失败或原生保护不可用则阻止播放。资源失效分支同时拦截原生 autoplay；CDP 注入失效或断开时，主进程保留整页静音并暂停。明确禁用、撤销 DSP 权限或卸载才移除贡献，上课清理仍具有最高优先级。

随应用升级的 NoiseLimiter 1.1.0 会按源码摘要识别原始 1.0.0 脚本并本地更新，不覆盖用户改写脚本，不恢复已卸载插件。旧基础模式的已保存强度迁移为动态强度，已有动态强度、输出上限、启用状态与授权保留。旧 API 的 `mode:"basic"` 只作为兼容别名统一进入动态算法，不存在另一条基础播放路径。

该处理不进行人声/鼓点源分离，也不能根据 dBFS 保证实体扬声器的声压。最高强度的鼓点接近轻微残留是目标，现场仍受音箱和系统音量影响。

## 固定来源与许可

包络、软拐点增益与限制算法参考并改写自 CamillaDSP，固定提交 `05e9cfcdf43c0dfe078ed3feb8af4c8bd701fd74`。上游提供 GPL-3.0 / MPL-2.0 双重许可，此处改写文件选用 MPL-2.0；上游原文件和两份许可证保留在 `vendor/noiselimiter/camilladsp`。整体应用继续使用 AGPL-3.0。

`native/noise-dsp` 是无第三方依赖的可移植 crate，`pnpm test:dynamics` 测试，`pnpm build:dynamics` 在规范 Linux / WSL 环境编译 WASM、写入源码与产物 SHA-256 清单。应用构建使用 `pnpm verify:dynamics` 验证固定资源和规范源码，不在不同宿主系统上静默改写资源；正式 Release 的 Linux job 会重建并核对产物。`pnpm pack:noiselimiter` 生成可导入 ZIP。应用只执行本地固定资源，不在线下载 DSP。新的压制算法随 Cplayer v1.4.1 宿主分发，1.1.0 ZIP 是插件入口，不能替代应用升级。

## 验证范围

可控信号测试覆盖静音、NaN/Inf、混合峰值、鼓点/高频突发、强度递增、旧模式兼容、多采样率与声道、无效配置及旁路。AudioWorklet 测试实际加载 WASM，并故障注入检查限幅后备。真实 Chromium 测试同时校验 100 强度与处理器故障时不超过 −36 dBFS、输出非零、页面不重载。

真实 B 站样本验证输出图连接、音频上下文 running、非零峰值与上限；此结果不代表所有视频或实体扬声器的主观效果均已验收。

### 与 v1.4.0 的可控鼓点对比

48 kHz、峰值 0.9、120 ms 衰减正弦鼓点、前置 100 ms 静音，左右声道 2:1；两版均为强度 100、用户上限 −12 dBFS。统计含起音和预读尾部的完整 500 ms 输出，RMS 不等同实体音量。

| 频率    | v1.4.0 峰值 / RMS   | 新动态峰值 / RMS    | RMS 变化  |
| ------- | ------------------- | ------------------- | --------- |
| 50 Hz   | 0.251189 / 0.034003 | 0.004921 / 0.000232 | −43.32 dB |
| 80 Hz   | 0.251189 / 0.037774 | 0.005741 / 0.000318 | −41.49 dB |
| 120 Hz  | 0.251189 / 0.035475 | 0.006289 / 0.000558 | −36.06 dB |
| 6000 Hz | 0.251189 / 0.011749 | 0.010267 / 0.000608 | −25.72 dB |

Rust 回归要求最大强度鼓点峰值小于 0.012、整段 RMS 至少比中档再低 14 dB，并覆盖 0/25/50/75/100 的单调衰减、声像、即时调强、直通及旧模式无法绕过动态处理。
