# 下载 Cplayer

请在 [GitHub Releases](https://github.com/DGHH-Skywalker/CPlayer/releases/latest) 获取正式版本：

- `Cplayer-<版本>-x64-setup.exe`：Windows x64 安装包
- `Cplayer-<版本>-x64-portable.exe`：单文件便携版
- `CarbonVPlayer-<版本>-source.zip`：对应版本完整源码
- `SHA256SUMS.txt`：SHA-256 校验文件

每个 Release 提供中国大陆镜像链接。镜像为第三方代理，下载后请核对同版本校验值。应用采用手动下载更新，不提供自动更新通道。当前发布 Windows x64 程序；macOS、Linux 可按源码开发说明自行构建，不将其他软件的发行包当作本项目版本。

[开发构建与验收产物](https://github.com/DGHH-Skywalker/CPlayer/actions) 仅用于开发验证，正式分发以 Release 为准。
