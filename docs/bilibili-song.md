# 哔哩Song（实验性）

## 使用方法

1. 在「设置 → 校园点歌 → B 站与 MV」打开「哔哩Song（实验性）」，默认关闭
2. 在应用侧栏打开哔哩哔哩，进入需要的 MV 视频页
3. 点击工具栏「哔哩Song · 加入播放列表」，追加至现有音乐队列；校园模式沿用 FIFO、去重、课间限制和拖拽排序
4. 队列轮到该项时自动显示 B 站页面，由原有网页播放器播放，原生音乐引擎停止
5. 视频自然结束后进入队列下一首；位于队尾时停止，不让 B 站自动续播或重复当前视频

播放、暂停、进度和系统媒体控制作用于当前网页项。离开页面、最小化或隐藏窗口暂停视频；需要继续播放时返回页面并点击播放。当前网页项播放期间，不允许站点跳转其他视频；请使用应用队列切歌。浏览器加载失败或崩溃时停止，提示重新加载或关闭 Core 后重试。

关闭实验开关停止正在播放的网页项，保留队列，可手动删除该项或重新启用功能。重启应用不会自动恢复旧视频。该功能不下载或解析音视频流，不保证会员、地区限制或被删除视频可播放。

## 播放边界

普通网页浏览与音乐仍保持独立；仅明确加入队列的网页项使用哔哩Song。队列仅保存 `source=bilibili`、稳定 ID、视频页 URL 和标题，分 P 纳入去重标识，不保存 Cookie 或视频流地址。

网页在主世界提前注册媒体事件捕获。自然结束时先关闭循环并阻止站点结束处理，随后暂停全部媒体，阻止后续 play 和分 P 跳转，只向主进程报告一次结束。主进程同步静音，验证操作 token 和校园代次后通知前端推进现有队列。前端还校验当前曲目和索引；旧页面事件不能推进新队列。

网页队列项拥有播放权时禁用原生引擎的加载、预载和交叉过渡；进入原生曲目前释放网页播放权。它使用独立传输接口，不触发普通 MV 的“暂停后恢复原生音乐”逻辑。校园截止始终先锁定、同步静音并作废网页控制，再停止音频、清空队列和持久化。

## 验证入口

- `pnpm test:web`：URL 校验、去重标识、一次结束、队尾停止、校园截止、过期操作和默认关闭
- `pnpm test:electron`：真实 Chromium 自然媒体结束、站点续播拦截、分 P 跳转拦截、主世界早期注入、独立 Session
- `pnpm test:bilibili-live`：在全新匿名会话实际解码指定公开网页，默认验证 Core 与免登录 1080P，输出 JSON 和截图到 `test-results`
- 可用 `BILIBILI_TEST_URL` 指定公开视频，`CPLAYER_CORE_ENABLED=false` 或 `CPLAYER_NO_LOGIN=false` 单独验证原生或关闭增强的状态

真实 B 站网络验收独立于 CI fixture；不能用受控页面通过推断所有视频、账号和网络环境均可用。
