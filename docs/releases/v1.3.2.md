# Cplayer v1.3.2 · 搜索时继续播放 B 站视频

- 修复 B 站播放期间打开顶部搜索框，网页失焦后视频暂停的问题
- 搜索、设置和菜单弹窗只遮住原生网页画面，播放进度继续；右下角原生按钮同时让位，不覆盖弹窗
- 关闭弹窗仅恢复画面，不擅自恢复用户手动暂停的视频
- 离开 B 站页面、隐藏/最小化窗口及上课截止仍按原规则暂停，哔哩Song 的代次与片尾交接保持有效
- 防止迟到的布局 IPC 在弹窗出现后重新显示网页

## 验证

新增 Vue 回归覆盖搜索弹窗、普通失焦、页面离开、窗口隐藏、音乐全屏及迟到 IPC。真实 Electron 验证焦点转移、文档可见性、进度推进和手动暂停保留；真实 B 站脚本增加相同检查。Windows 便携版验收实际打开应用顶部搜索弹窗，在独立网页内播放受控媒体，检查不暂停、关闭后保留手动暂停、离开暂停、弹窗打开期间上课仍暂停。

实体扬声器、真实睡眠唤醒、账号及多显示器现场交互仍需对应设备，不由自动测试替代。
