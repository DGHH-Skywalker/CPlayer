# Cplayer v1.4.0 · 插件中心与 NoiseLimiter

- 启动优先准备播放与歌词，历史歌曲先于首页推荐派发；设置、登录、评论、识曲和歌单工具按点击加载，缓存维护与外部服务延后
- 修复主进程拆包后页面、preload、图标与 worker 的相对路径问题
- 设置空白处 3 秒内连按 5 次 Enter，打开本次启动有效的「插件中心」，与校园点歌平级，沿用应用样式
- API 6：兼容原有插件，新增应用设置、页面/浏览器控制、用户选定文件、资源与 DSP 参数接口，支持 JS 和 ZIP 导入
- 首个插件 NoiseLimiter 默认启用「动态限制」，提供基础/动态强度、输出上限、低频状态；原生音乐与 B 站/哔哩Song 共用 Rust/WASM DSP
- 哔哩Song 拖动先预览、松手提交一次定位；保留暂停状态，过滤旧确认，显示缓冲区与定位状态；完整控件留在底栏，避免被原生网页遮挡
- 上课截止优先级保持最高，插件及网页回调不能恢复旧播放；更新插件保持保护，资源/处理器/CDP故障保守限幅或静音，暂停媒体时挂起音效上下文
- 保留 B 站搜索失焦继续播放、单视频结束后推进应用队列，以及独立 Session 与本地固定 Core
