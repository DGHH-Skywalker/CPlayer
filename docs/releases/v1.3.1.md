# Cplayer v1.3.1 · 哔哩Song 修复

- 哔哩哔哩默认打开 `search.bilibili.com`，移除返回点歌、后退、前进、地址栏和网页标题
- 哔哩Song 入队按钮移到模块右下角，使用独立本地原生视图置于网页上方；没有远程特权 IPC
- 修复网页原生视图覆盖底部播放控制栏的问题，兼容播放栏入场动画及浮动布局
- 启动 MV 时折叠音乐全屏页；结束后先停止网页，再返回音乐界面并交接队列下一项，队尾停止
- 强化 window 捕获、循环关闭和播放器重建监听，阻止站点抢先续播，保持课间截止与操作代次保护
