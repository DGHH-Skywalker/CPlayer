# Cplayer v1.3.0 · CarbonVPlayer

首个校园点歌正式版本，Windows x64 安装包和便携版均由 GitHub Actions 从本标签源码构建。

## 主要功能

- 普通音乐模式与独立校园点歌模式，搜索首页、FIFO 点歌、去重及拖拽排序
- 上海时区课间作息、特殊日期、上课强制停止并清空队列、迟到异步任务保护
- 独立 B 站浏览器、MV 剧场、固定本地 Core、音频协调与浏览数据管理
- 实验性「哔哩Song」：将当前 MV 加入队列，视频结束后阻止站点续播并交接下一首；默认关闭
- Cplayer 项目介绍、下载入口与独立发布流程，移除旧品牌的产品宣传和自动更新入口
