# Cplayer v1.4.1 · 更强的动态压制

- NoiseLimiter 只保留动态强度与输出上限滑块，移除模式选择和基础模式
- 大幅增强高强度低频、鼓点起音及尖锐瞬态压制；100 强度优先安静，音色会变薄
- 四阶分频配合 5 ms 真正预读，避免第一下鼓点在检测跟上前漏出；音乐和 B 站共用 Rust/WASM 算法
- 最高强度输出不超过 −36 dBFS，初始化和故障保护也保留该限制，无补偿增益
- 原版旧插件本地升级并迁移参数，保留启用、授权和卸载状态，不覆盖用户改写脚本
- 保留 v1.4.0 的插件中心、渐进启动、哔哩Song 精确定位和校园上课硬截止
